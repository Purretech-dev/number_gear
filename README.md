# Number Gear

Number Gear is a pre-primary maths learning app.

## Levels

- Level 1 helps children identify numbers from 1 to 100 using number signs, words, and tens/ones visuals.
- Level 2 unlocks after Level 1 is completed and uses a movable circular number gear for counting patterns.

## Run Locally

Open `gear.html` in a browser, or run the local preview server:

```bash
node server.mjs
```

Then open:

```text
http://127.0.0.1:4173
```
